# Credit Card Fraud Detection System

## Description

This project analyzes credit card transaction data to identify fraudulent transactions using data analysis, visualization, and machine learning techniques. It helps financial institutions detect fraud patterns and improve transaction security.

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Plotly
* Scikit-learn
* KaggleHub

## Features

* Fraud transaction analysis
* Risk level classification
* Data cleaning and preprocessing
* Exploratory Data Analysis (EDA)
* Interactive dashboards using Plotly
* Linear Regression model
* Correlation analysis

## Dataset

The dataset contains credit card transaction records with features such as transaction time, amount, and fraud status (Class).

## Model

**Linear Regression** is used to predict transaction amounts based on transaction time.

## Key Insights

* Fraudulent transactions represent a small portion of total transactions.
* Transaction amount patterns help identify suspicious activities.
* Risk levels categorize transactions as Low, Medium, or High Risk.
* Data visualization improves fraud detection analysis.

## Output

* Fraud distribution analysis
* Risk classification reports
* Statistical summaries
* Interactive dashboards
* Model evaluation using R² Score and MSE

## Conclusion

The Credit Card Fraud Detection System uses machine learning and data analytics to study transaction behavior, identify potential fraud, and support secure financial transactions.
